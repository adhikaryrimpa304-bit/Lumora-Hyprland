# LUMORA visual update — ML4W-inspired, LUMORA-owned theme

- Rofi layout follows the spacious ML4W launcher approach, recoloured in LUMORA midnight black (#090A12), violet (#B026FF) and cyan (#00F0FF).
- Hyprlock uses a blurred LUMORA wallpaper, clock, username and rounded password field.
- Kitty replaces foot and runs Bash, with translucent background and Hyprland compositor blur.
- Bash gets a minimal violet/cyan prompt and common aliases.
- GRUB theme uses a clean centred menu and LUMORA wallpaper/signature palette, inspired by modern minimal boot menus rather than copying another distribution's assets.
- Hypridle locks after 10 minutes and blanks displays after 15 minutes.

## Validation status
These are source-level configuration changes. Syntax checks can catch basic errors, but this theme has not been validated in a built ISO or booted in a VM. GRUB theme integration depends on the final image's GRUB configuration and bootloader packaging. Kitty transparency blur requires Hyprland compositor support.
